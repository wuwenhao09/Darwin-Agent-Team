# Darwin Agent Team Website

A static, responsive team website with **About**, **Research**, and **Contact** navigation. No build step or third-party dependencies are required.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Update content

- Team landing section: `index.html`
- Research cards and links: `research.html`
- Shared styling: `styles.css`
- About hero image: `assets/images/about-hero.webp`
- Research images: `assets/images/`
- Local paper PDFs: `assets/papers/`

The About artwork is temporary reference artwork from MirroS and can be replaced by overwriting the two `about-*.webp` files.
