# Darwin Agent 标志：分叉 D

标志围绕团队的主要研究方向 **Harness 自进化** 设计。D 是 Darwin 的首字母；拆开的直角支架与回环弧线共同构成 D，表达可以组合、调整的 Agent Harness；内部的不对称分叉借鉴达尔文的演化谱系，表达变异、分支与选择。回环轮廓呼应执行、反馈和持续改进。

标志采用单色几何轮廓。网站导航栏、Research 图的根节点和 favicon 已应用此标志，图形文件共用同一几何设计。

## 文件

| 文件 | 用途 |
| --- | --- |
| `darwin-agent-mark.svg` / `.png` | 橙色独立标志，透明背景；PNG 为 1024 × 1024 |
| `darwin-agent-mark-ink.svg` | 深色单色标志，用于浅色背景 |
| `darwin-agent-mark-white.svg` | 浅色单色标志，用于深色背景 |
| `darwin-agent-logo.svg` / `.png` | 橙色标志 + 深色 Darwin Agent 字标，透明背景 |
| `darwin-agent-logo-dark.svg` / `.png` | 橙色标志 + 浅色 Darwin Agent 字标，透明背景 |
| `darwin-agent-avatar.svg` / `.png` | 深色圆角头像；PNG 为 1024 × 1024 |
| `brand-preview.svg` / `.png` | 标志概念、字标、配色及应用预览 |
| 根目录 `favicon.svg` / `favicon.png` | 浏览器图标；PNG 为 64 × 64 |

SVG 可以在 Figma、Illustrator、Inkscape 等软件中继续编辑。字标已转换为矢量轮廓，展示时无需安装字体；字形基于 Arial Bold，并调整了字距。横向字标 PNG 宽 1600 px。

## 配色与使用

- 品牌橙：`#FF6801`。
- 深色字标：`#17171B`。
- 浅色字标：`#F7F6F8`。
- 头像底色：`#101315`。
- 推荐独立标志使用尺寸至少 24 px；浏览器图标可使用 16 px。
- 外轮廓四周保留至少相当于标志实际宽度 1/8 的留白。
- 保持原始宽高比、分叉比例和支架之间的间隙；避免为小尺寸版本增加文字或细节。
